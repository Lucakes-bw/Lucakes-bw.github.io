# 算法设计示例

《数据结构 → 算法设计》一章中所有的示例程序，C11，每个程序独立。文章中的输出和时间都来自这些程序
（Apple M6，Apple Clang 21，`-O2`）。

| 文件 | 文章 |
|---|---|
| `backtracking.c` | 递归与回溯：全排列、子集、N 皇后 |
| `dp_basics.c` | 动态规划（一）：斐波那契、零钱兑换、最小路径和 |
| `knapsack.c` | 动态规划（二）：背包问题 |
| `sequence.c` | 动态规划（三）：最长递增子序列、最长公共子序列、编辑距离 |
| `greedy.c` | 贪心：活动选择、跳跃游戏 |
| `two_pointers.c` | 双指针与滑动窗口 |
| `kmp.c` | 字符串匹配：KMP |

```bash
make            # 编译
make run        # 运行全部
```

每个程序都用暴力枚举或者另一种写法检查结果（`CHECK`），检查失败会立即退出。

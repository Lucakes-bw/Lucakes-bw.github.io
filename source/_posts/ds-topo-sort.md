## 1. 问题

计算机专业的几门课之间有先修关系：学数据结构之前要先学 C 语言和离散数学，学算法之前要先学数据结构和离散数学……怎样安排一个学习顺序，让每门课在学之前，它的先修课都已经学过了？

把每门课看作一个顶点，「A 是 B 的先修课」看作一条有向边 A → B，就得到了一个**有向图**。我们要找的是所有顶点的一个排列，使得**每条边 A → B 中，A 都排在 B 的前面**。这样的排列叫作**拓扑排序**。

拓扑排序存在的条件是：图中**没有环**。如果 A 是 B 的先修课，B 又是 A 的先修课，那么哪门课都没法先学。没有环的有向图叫作**有向无环图**（DAG，Directed Acyclic Graph）。

拓扑排序的应用非常多：

- 编译器和构建工具（Make、CMake）按依赖关系决定编译的顺序；
- 包管理器（npm、apt）按依赖关系决定安装的顺序；
- 电子表格按单元格之间的引用决定计算的顺序，并发现「循环引用」；
- 项目管理中安排有先后依赖的任务。

有向图用邻接表存储，和无向图的区别只是每条边只存一个方向：

```c
typedef struct { int* to; int size, cap; } AdjList;
typedef struct { int n; AdjList* adj; } Digraph;

void addArc(Digraph* g, int u, int v)          // 有向边 u → v
{
    AdjList* a = &g->adj[u];
    if (a->size == a->cap) { a->cap = a->cap ? a->cap * 2 : 4; a->to = realloc(a->to, a->cap * sizeof(int)); if (!a->to) exit(1); }
    a->to[a->size++] = v;
}
```

## 2. Kahn 算法

一个顶点的**入度**是指向它的边的条数，也就是这门课有几门先修课。思路很自然：

1. 入度为 0 的课没有先修要求，可以先学，放进队列；
2. 从队列中取出一门课学完，它指向的每门课的入度减 1（少了一门没学的先修课）；
3. 某门课的入度减到 0，说明它的先修课都学完了，放进队列；
4. 重复 2、3，直到队列为空。

```c
// Kahn 算法：反复取出入度为 0 的顶点。返回排好的顶点个数，小于 n 说明有环
int topoKahn(const Digraph* g, int* order)
{
    int* indeg = calloc(g->n, sizeof(int));
    int* queue = malloc(g->n * sizeof(int));
    int head = 0, tail = 0, k = 0;
    for (int u = 0; u < g->n; ++u)
        for (int i = 0; i < g->adj[u].size; ++i) indeg[g->adj[u].to[i]]++;
    for (int v = 0; v < g->n; ++v)
        if (indeg[v] == 0) queue[tail++] = v;   // 没有前置要求的，可以先做
    while (head < tail) {
        int u = queue[head++];
        order[k++] = u;
        for (int i = 0; i < g->adj[u].size; ++i) {
            int v = g->adj[u].to[i];
            if (--indeg[v] == 0) queue[tail++] = v;   // v 的前置要求都完成了
        }
    }
    free(indeg); free(queue);
    return k;
}
```

在演示中，每个顶点下方是课程名和当前的入度；学完一门课后，从它出发的边变成虚线，表示这条先修关系已经满足了：

### 2.1 检测环

如果图中有环，环上的顶点的入度永远不会减到 0（每个顶点都在等环上的前一个顶点），它们永远不会进入队列。所以**排出的顶点个数小于 n，就说明有环**。演示中的第二个按钮加上了一条「编译原理 → C 语言」的边，形成了环 C 语言 → 数据结构 → 编译原理 → C 语言：

```c
addArc(&g, 6, 0);                           // 加一条边：编译原理 → C 语言，形成环
printf("加上 编译原理 → C 语言 之后：Kahn 只排出了 %d 个，DFS 返回 %d\n", topoKahn(&g, order), topoDFS(&g, order));
```

```

```

只有不在环上、也不依赖于环的离散数学能被排出来。

## 3. 基于 DFS 的拓扑排序

另一种方法用 DFS：对一个顶点，**先递归地处理完它的所有后继，再把它加入结果**（后序）。这样，每个顶点都在它所有后继之后加入结果。把结果**反转**，就是拓扑排序。

检测环需要区分三种状态，通常用三种颜色表示：

- **白色**：还没有访问；
- **灰色**：正在访问，也就是它还在递归栈中，它的后继还没有处理完；
- **黑色**：已经处理完。

DFS 时如果走到了一个**灰色**的顶点，说明从这个顶点出发又走回了它自己，有环。

```c
enum { WHITE, GRAY, BLACK };                    // 未访问、正在访问（在递归栈中）、已完成
static int dfsVisit(const Digraph* g, int u, int* color, int* order, int* k)
{
    color[u] = GRAY;
    for (int i = 0; i < g->adj[u].size; ++i) {
        int v = g->adj[u].to[i];
        if (color[v] == GRAY) return 0;         // 走回了递归栈中的顶点：有环
        if (color[v] == WHITE && !dfsVisit(g, v, color, order, k)) return 0;
    }
    color[u] = BLACK;
    order[(*k)++] = u;                          // 后序：u 的后继都已经在结果中了
    return 1;
}

int topoDFS(const Digraph* g, int* order)
{
    int* color = calloc(g->n, sizeof(int));
    int k = 0, ok = 1;
    for (int u = 0; u < g->n && ok; ++u)
        if (color[u] == WHITE) ok = dfsVisit(g, u, color, order, &k);
    for (int i = 0; i < k / 2; ++i) { int t = order[i]; order[i] = order[k - 1 - i]; order[k - 1 - i] = t; }
    free(color);
    return ok ? k : -1;
}
```


这个顺序和 Kahn 算法的不同，但同样满足所有的先修关系。**拓扑排序通常不是唯一的**：没有先后关系的两门课（比如 C 语言和离散数学），谁先谁后都可以。

为什么无向图判环（上一篇的练习）只需要两种状态，有向图却要三种？在有向图中，走到一个已经访问过的顶点不一定有环：比如 A → B、A → C、C → B，从 A 出发先访问 B（变黑），再从 C 走到 B，B 已经访问过，但没有环。只有走到**灰色**（还在递归栈中）的顶点，才说明形成了一个回路。

两个程序都用 `-fsanitize=address,undefined` 和 `leaks` 检查过。

## 4. 常见错误

1. **对有环的图求拓扑排序，却不检查结果的个数**：输出了一个不完整的序列。
2. **有向图判环只用「已访问」一种标记**：会把不是环的情况误判为环。
3. **基于 DFS 的方法忘记反转结果**：得到的是逆拓扑序。
4. **边的方向搞反**：「A 是 B 的先修课」应该是 A → B。
5. **以为拓扑排序是唯一的**：用拓扑序做比较测试时，要检查它是否满足所有的边，而不是和某个固定的答案比较。

## 5. 小结

- 拓扑排序把有向无环图的顶点排成一列，每条边都从前指向后；有环时不存在拓扑排序
- Kahn 算法：反复取出入度为 0 的顶点，并减少它的后继的入度；排出的个数小于 n 说明有环
- DFS 方法：后序加入结果再反转；用白、灰、黑三种颜色，遇到灰色顶点说明有环
- 两种方法都是 O(n + m)；拓扑排序通常不唯一
- 应用：编译和安装的依赖顺序、任务调度、检测循环依赖

2. 怎样判断一个有向无环图的拓扑排序是否**唯一**？
3. 一个项目有若干个任务，每个任务需要一定的天数，有些任务必须在另一些任务完成之后才能开始，任务可以同时进行。怎样求出整个项目最少需要多少天？

1. 例如：离散数学 → C 语言 → 数据结构 → 操作系统 → 算法 → 计算机网络 → 编译原理。检查每条边：C 语言和离散数学都在数据结构之前；数据结构、离散数学在算法之前；C 语言、数据结构在操作系统之前；操作系统在计算机网络之前；算法、数据结构在编译原理之前，都满足。

2. 用 Kahn 算法：如果在整个过程中，**队列中始终最多只有一个顶点**，拓扑排序就是唯一的；只要某一时刻队列中有两个或以上的顶点，它们的先后就可以交换，排序不唯一。唯一时，拓扑序中每相邻的两个顶点之间都有一条边。

3. 这叫**关键路径**问题。按拓扑顺序处理每个任务：一个任务最早的完成时间 = 它所有前置任务最早完成时间的最大值 + 它自己的天数（没有前置任务的从 0 开始）。按拓扑序计算可以保证处理一个任务时，它的前置任务都已经算好了。所有任务最早完成时间的最大值就是项目的最短工期。决定这个最大值的那条依赖链叫作**关键路径**，链上任何一个任务延期，整个项目都会延期。

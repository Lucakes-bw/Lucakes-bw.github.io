> **本文目标**：理解声音是怎样变成数字的：采样率、位深、声道数；会算 PCM 数据的大小和码率；分清交错和平面两种存储方式；读懂 WAV 文件的格式，会自己写 WAV 文件；理解 dBFS、削顶和混叠。
>
> **前置知识**：上一篇《像素与 YUV》（测试视频的准备）；C 语言的文件读写和 `<stdint.h>` 中的定长整数。
>
> **实验环境**：macOS 27.0（Apple M6），Apple Clang 21，FFmpeg 9.0。

## 1. 声音怎样变成数字

1. **采样**（sampling）：每隔固定的时间测一次电压。每秒测多少次叫**采样率**（sample rate），单位 Hz。
2. **量化**（quantization）：把测到的值四舍五入到最近的一个档位，用整数表示。每个值用多少位存叫**位深**（bit depth）。

得到的一串整数，就是 **PCM**（Pulse Code Modulation，脉冲编码调制）数据。它是音频的「原始数据」，地位和视频中的 YUV 一样：麦克风采集出来的是 PCM，解码器输出的是 PCM，声卡播放的也是 PCM。MP3、AAC 这些编码格式，压缩的对象都是 PCM。

### 1.2 采样率：每秒测多少次

采样率决定了能记录多高的频率。**采样定理**（奈奎斯特定理）说：采样率至少是信号最高频率的 2 倍，才能把信号完整还原。人耳能听到的范围大约是 20 Hz ～ 20 kHz，所以音频的采样率一般在 40 kHz 以上：

| 采样率 | 能记录的最高频率 | 用途 |
|---|---|---|
| 8000 Hz | 4 kHz | 电话 |
| 16000 Hz | 8 kHz | 语音识别、网络通话 |
| 44100 Hz | 22.05 kHz | CD、大部分音乐文件 |
| **48000 Hz** | 24 kHz | 视频、直播、电影，本专栏使用 |
| 96000 Hz | 48 kHz | 录音棚 |

采样率不够，高频会变成什么？不是简单地「丢掉」，而是变成一个**不存在的低频声音**，第 5 节会实际听到。

### 1.3 位深：每次测量用多少位

位深决定了量化的精细程度。16 位有 65536 个档位，范围是 −32768 ～ 32767。每多 1 位，档位翻一倍，能表示的最大音量和最小音量之比（**动态范围**）大约增加 6 dB，16 位约 96 dB，已经超过了普通环境下人耳的需要。

| 格式 | FFmpeg 中的名字 | 每个采样 | 范围 |
|---|---|---|---|
| 8 位无符号 | `u8` | 1 字节 | 0 ～ 255，128 是静音 |
| **16 位有符号** | `s16` | 2 字节 | −32768 ～ 32767，0 是静音 |
| 32 位有符号 | `s32` | 4 字节 | −2³¹ ～ 2³¹−1 |
| 32 位浮点 | `flt` | 4 字节 | −1.0 ～ 1.0 |

16 位整数（`s16`）最常用，CD 和大部分 WAV 文件都是它。浮点格式（`flt`）在处理时最方便：混音、调音量时超出 ±1.0 也不会马上出错，FFmpeg 的 AAC 解码器输出的就是浮点数。

同一时刻所有声道的一组采样，叫一个**采样帧**（sample frame）。注意这里的「帧」和视频的帧、后面 AAC 的帧都不是一回事，读文档时要看上下文。

### 1.5 PCM 有多大

PCM 没有压缩，大小可以直接算：

```
码率 = 采样率 × 位深 × 声道数
```

48000 Hz、16 位、双声道：48000 × 16 × 2 = 1536000 位/秒 = **1536 kbps**，每秒 192000 字节，一分钟约 11 MB。测试视频中 AAC 音轨的码率只有约 128 kbps，压缩了 12 倍。

和视频比，音频的数据量小得多：上一篇算过，720p 的 YUV 每秒 33 MB，是音频的 170 多倍。所以音视频压缩中，视频编码是主要矛盾。

### 2.2 程序

生成一段 2 秒、440 Hz（钢琴中央 A 的音高）的正弦波，双声道，左声道一直响，右声道只响前 1 秒：

```c
// gen_wav.c：生成 2 秒 440 Hz 的正弦波，保存成 WAV
#include <stdio.h>
#include <stdint.h>
#include <math.h>

static void put_le16(FILE *f, uint16_t v) { fputc(v & 0xff, f); fputc(v >> 8, f); }
static void put_le32(FILE *f, uint32_t v) { put_le16(f, v & 0xffff); put_le16(f, v >> 16); }

// 写 44 字节的 WAV 头：RIFF 块里有 fmt 和 data 两个子块
static void write_wav_header(FILE *f, int rate, int channels, int bits, uint32_t data_size)
{
    int block_align = channels * bits / 8;      // 一个采样点（所有声道）占几个字节
    fwrite("RIFF", 1, 4, f);
    put_le32(f, 36 + data_size);                // 后面还有多少字节
    fwrite("WAVE", 1, 4, f);
    fwrite("fmt ", 1, 4, f);
    put_le32(f, 16);                            // fmt 块的长度
    put_le16(f, 1);                             // 1 = PCM
    put_le16(f, channels);
    put_le32(f, rate);
    put_le32(f, rate * block_align);            // 每秒字节数
    put_le16(f, block_align);
    put_le16(f, bits);
    fwrite("data", 1, 4, f);
    put_le32(f, data_size);
}

int main(void)
{
    const int rate = 48000, channels = 2, seconds = 2;
    const double freq = 440.0, amplitude = 0.5;      // 0.5 = 满幅度的一半
    int n = rate * seconds;

    FILE *f = fopen("sine440.wav", "wb");
    write_wav_header(f, rate, channels, 16, n * channels * 2);
    for (int i = 0; i < n; i++) {
        double t = (double)i / rate;                  // 第 i 个采样点的时刻
        int16_t s = (int16_t)lrint(amplitude * 32767 * sin(2 * M_PI * freq * t));
        put_le16(f, s);                               // 左声道
        put_le16(f, i < n / 2 ? s : 0);               // 右声道：后一秒静音
    }
    fclose(f);
    printf("写入 %d 个采样点，数据 %d 字节\n", n, n * channels * 2);
    return 0;
}
```

第 i 个采样点的值是 `sin(2π × 频率 × 时刻)`，乘以 32767 变成 16 位整数。振幅取 0.5，也就是满幅度的一半，留出余量，后面放大音量时用得到。

### 3.1 拆开左右声道

交错格式中，每 4 个字节是一个采样帧：前 2 字节是左声道，后 2 字节是右声道。逐帧读出来，分别写到两个文件：

```c
// pcm_split.c：把 16 位双声道交错 PCM 拆成左、右两个单声道文件
#include <stdio.h>
#include <stdint.h>

int main(int argc, char *argv[])
{
    if (argc != 2) { fprintf(stderr, "用法: %s 输入.pcm\n", argv[0]); return 1; }
    FILE *in = fopen(argv[1], "rb");
    FILE *fl = fopen("out_l.pcm", "wb");
    FILE *fr = fopen("out_r.pcm", "wb");
    int16_t frame[2];                     // 一个采样点：L R
    long n = 0;
    while (fread(frame, sizeof(int16_t), 2, in) == 2) {
        fwrite(&frame[0], sizeof(int16_t), 1, fl);
        fwrite(&frame[1], sizeof(int16_t), 1, fr);
        n++;
    }
    printf("%ld 个采样点\n", n);
    fclose(in); fclose(fl); fclose(fr);
    return 0;
}
```

### 3.2 电平：这段声音有多响

数字音频的音量用 **dBFS**（相对满刻度的分贝）表示：16 位的满刻度是 32768，记为 0 dBFS；数值减半，大约 −6 dB；静音是负无穷。dBFS 永远是 0 或负数，越接近 0 越响。

衡量音量常用两个量：

- **峰值**（peak）：一段时间内绝对值最大的那个采样，决定会不会削顶。
- **均方根**（RMS）：所有采样的平方取平均再开方，更接近人耳感受到的响度。

逐秒计算这两个值：

```c
// pcm_level.c：每秒计算一次峰值和均方根电平（dBFS）
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <math.h>

int main(int argc, char *argv[])
{
    if (argc != 4) { fprintf(stderr, "用法: %s 输入.pcm 采样率 声道数\n", argv[0]); return 1; }
    int rate = atoi(argv[2]), ch = atoi(argv[3]);
    FILE *in = fopen(argv[1], "rb");
    int16_t s;
    long count = 0;
    int sec = 0, peak = 0;
    double sum = 0;
    while (fread(&s, sizeof s, 1, in) == 1) {
        if (abs(s) > peak) peak = abs(s);
        sum += (double)s * s;
        if (++count == (long)rate * ch) {            // 攒够一秒
            double rms = sqrt(sum / count);
            printf("第 %2d 秒  峰值 %6.1f dBFS  RMS %6.1f dBFS\n", sec++,
                   20 * log10((peak + 1e-9) / 32768.0), 20 * log10((rms + 1e-9) / 32768.0));
            count = 0; sum = 0; peak = 0;
        }
    }
    fclose(in);
    return 0;
}
```

```bash
clang -O2 -o pcm_level pcm_level.c -lm
./pcm_level bbb.pcm 48000 2
```

### 3.3 调音量与削顶

调音量就是把每个采样乘以一个系数。乘以 2，音量增加 6 dB；乘以 0.5，减少 6 dB。问题在于 16 位整数最大只能到 32767，乘出来超过范围的值只能截断成最大值，这叫**削顶**（clipping）。被削顶的波形顶部变成平的，听起来会有刺耳的破音：

```c
// pcm_gain.c：把 16 位 PCM 的音量乘以一个系数，统计被削顶的采样
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <math.h>

int main(int argc, char *argv[])
{
    if (argc != 4) { fprintf(stderr, "用法: %s 输入.pcm 输出.pcm 倍数\n", argv[0]); return 1; }
    double gain = atof(argv[3]);
    FILE *in = fopen(argv[1], "rb"), *out = fopen(argv[2], "wb");
    int16_t s;
    long total = 0, clipped = 0;
    while (fread(&s, sizeof s, 1, in) == 1) {
        long v = lrint(s * gain);
        if (v > 32767)  { v = 32767;  clipped++; }   // 超出 16 位的范围，只能截断
        if (v < -32768) { v = -32768; clipped++; }
        int16_t o = (int16_t)v;
        fwrite(&o, sizeof o, 1, out);
        total++;
    }
    printf("倍数 %.2f（%+.1f dB）：%ld 个采样，削顶 %ld 个（%.3f%%）\n",
           gain, 20 * log10(gain), total, clipped, 100.0 * clipped / total);
    fclose(in); fclose(out);
    return 0;
}
```

## 4. 采样率不够会怎样：混叠

1.2 节说过，采样率至少要是最高频率的 2 倍。16 kHz 的采样率最高只能记录 8 kHz 的声音，那如果硬要用它记录一个 15 kHz 的声音呢？

下面的程序先生成 1 秒 48 kHz 的 15 kHz 正弦波，再用两种方法降到 16 kHz：

- **直接丢采样**：每 3 个采样留 1 个；
- **先平均再丢**：每 3 个采样取平均值，相当于一个最简单的低通滤波器。

然后通过数过零次数估计频率（正弦波每个周期穿过零点两次），并计算 RMS：

```c
// alias.c：直接丢采样把 48 kHz 降到 16 kHz，看 15 kHz 的声音变成了什么
#include <stdio.h>
#include <stdint.h>
#include <math.h>

#define N 48000                       // 1 秒

// 数过零次数估计频率：正弦波每个周期过零两次
static double zero_cross_freq(const double *x, int n, int rate)
{
    int crossings = 0;
    for (int i = 1; i < n; i++)
        if ((x[i - 1] < 0) != (x[i] < 0)) crossings++;
    return crossings / 2.0 * rate / n;
}

static double rms(const double *x, int n)
{
    double s = 0;
    for (int i = 0; i < n; i++) s += x[i] * x[i];
    return sqrt(s / n);
}

static void save_wav(const char *name, const double *x, int n, int rate)
{
    FILE *f = fopen(name, "wb");
    uint32_t data = n * 2, v32;
    uint16_t v16;
    fwrite("RIFF", 1, 4, f); v32 = 36 + data; fwrite(&v32, 4, 1, f);
    fwrite("WAVEfmt ", 1, 8, f); v32 = 16; fwrite(&v32, 4, 1, f);
    v16 = 1; fwrite(&v16, 2, 1, f); fwrite(&v16, 2, 1, f);      // PCM，单声道
    v32 = rate; fwrite(&v32, 4, 1, f); v32 = rate * 2; fwrite(&v32, 4, 1, f);
    v16 = 2; fwrite(&v16, 2, 1, f); v16 = 16; fwrite(&v16, 2, 1, f);
    fwrite("data", 1, 4, f); fwrite(&data, 4, 1, f);
    for (int i = 0; i < n; i++) { int16_t s = (int16_t)lrint(x[i] * 32767); fwrite(&s, 2, 1, f); }
    fclose(f);
}

int main(void)
{
    static double src[N], drop[N / 3], avg[N / 3];
    for (int i = 0; i < N; i++)
        src[i] = 0.5 * sin(2 * M_PI * 15000 * i / 48000.0);

    for (int i = 0; i < N / 3; i++) {
        drop[i] = src[i * 3];                                        // 每 3 个留 1 个
        avg[i] = (src[i * 3] + src[i * 3 + 1] + src[i * 3 + 2]) / 3; // 先取平均再留
    }
    printf("原始 48 kHz：     频率 %7.1f Hz，RMS %.4f\n", zero_cross_freq(src, N, 48000), rms(src, N));
    printf("直接丢采样 16 kHz：频率 %7.1f Hz，RMS %.4f\n", zero_cross_freq(drop, N / 3, 16000), rms(drop, N / 3));
    printf("先平均再丢 16 kHz：频率 %7.1f Hz，RMS %.4f（%.1f dB）\n", zero_cross_freq(avg, N / 3, 16000),
           rms(avg, N / 3), 20 * log10(rms(avg, N / 3) / rms(drop, N / 3)));
    save_wav("tone15k_48k.wav", src, N, 48000);
    save_wav("tone15k_drop16k.wav", drop, N / 3, 16000);
    return 0;
}
```

**混叠一旦发生就无法去除**：从 16 kHz 的数据中，根本分不清这个 1 kHz 是原来就有的，还是 15 kHz 混叠下来的。所以必须在降低采样率**之前**，先把超过新采样率一半的频率滤掉。

「先平均再丢」就是这个思路，但 3 点平均是个很粗糙的滤波器，只把混叠压低了 22 dB，仍然听得见。FFmpeg 的重采样器用的是精心设计的低通滤波器：

```bash
ffmpeg -i tone15k_48k.wav -ar 16000 tone15k_ffmpeg16k.wav
ffmpeg -i tone15k_ffmpeg16k.wav -af astats -f null - 2>&1 | grep "RMS level"
```

RMS 从 −9 dB 降到了约 −60 dB，15 kHz 的声音被干净地去掉了，这才是正确的结果：16 kHz 采样率本来就不能表示 15 kHz 的声音。开头一小段的能量是滤波器刚启动时的过渡。以后需要改变采样率时，用 FFmpeg 的 `libswresample`（第 3 章），不要自己丢采样。

同样的道理也适用于图像：把图片缩小时直接隔一个像素取一个，细密的条纹会变成粗大的波纹（摩尔纹），正确的做法也是先模糊再缩小。

## 5. 小结

- 声音经过**采样**（每秒取多少个值）和**量化**（每个值用多少位）变成 PCM，PCM 是音频的原始数据。
- 视频常用 48 kHz、16 位或浮点、双声道；PCM 码率 = 采样率 × 位深 × 声道数，48 kHz 16 位立体声是 1536 kbps。
- 多声道有交错（LRLR）和平面（LLL…RRR…）两种存法；FFmpeg 中名字带 `p` 的是平面格式。
- WAV = 44 字节的头 + PCM；PCM 本身不带参数，播放时必须指定格式、采样率、声道数。
- 音量用 dBFS 表示；整数 PCM 放大超出范围会削顶，信息永久丢失。
- 采样率低于信号最高频率的 2 倍时，高频会混叠成低频，必须先低通滤波再降采样。

下一篇把前两篇的数字放在一起：一秒钟的原始音视频有多大，压缩后又有多大，以及视频为什么能压缩上百倍。

   ```c
       double freq = 261.63 * pow(2, steps[k] / 12.0);
       for (int i = 0; i < per_note; i++) {
           put_le16(f, (int16_t)lrint(0.5 * 32767 * sin(phase)));
           phase += 2 * M_PI * freq / rate;           // 累加相位，换音时波形不会跳变
       }
   }
   ```

   算出的频率是 261.63、293.67、329.63、349.23、392.00、440.01、493.89 Hz，第 6 个音正好是 440 Hz 的 A4。单声道 48 kHz 16 位，2.1 秒的数据是 201600 字节，加上 44 字节的头，文件 201644 字节。

   注意这里没有用 `sin(2π × 频率 × t)`，而是累加相位。如果每个音都从 t 算起，换音的那一刻，前后两段正弦波的值对不上，波形会突然跳一下，听到「咔」的一声。累加相位保证波形是连续的。

2. 要改的地方有三处：位深写 8，每个采样帧 1 字节（每秒字节数 = 采样率），采样值以 128 为中心：

   ```c
   put_le16(f, 1); put_le16(f, 8);                    // 每个采样帧 1 字节，8 位
   ...
   fputc((int)lrint(128 + s * 127), f);               // 无符号：以 128 为中心
   ```

   `ffprobe` 识别为 `codec_name=pcm_u8`、`bits_per_sample=8`。2 秒单声道的文件 96044 字节，是 16 位的一半。8 位只有 256 档，量化误差比 16 位大 256 倍，动态范围只有约 48 dB，在安静的段落中通常能听出「沙沙」的底噪，早期电脑游戏的音效就是这种音质。

3. 设一共有 n 个采样帧，交错格式中第 i 帧第 c 个声道在 `src[i * 2 + c]`，平面格式中在 `dst[c * n + i]`：

   ```c
   for (long i = 0; i < n; i++)
       for (int c = 0; c < 2; c++) {
           if (to_planar) dst[c * n + i] = src[i * 2 + c];   // 第 c 个声道放在第 c 块
           else           dst[i * 2 + c] = src[c * n + i];
       }
   ```

   把 `bbb.pcm` 转成平面格式再转回来，和原文件用 `cmp` 比较完全相同。平面格式文件的前 960000 字节和 3.1 节拆出来的 `out_l.pcm` 也完全相同：平面格式就是把各个声道首尾相接。

4. 逐个采样帧计算 `(L - R) / 2`（除以 2 防止两个 16 位数相减溢出），输出单声道。作为对比，用 `(L + R) / 2` 得到「中间」的成分，两者的 RMS 电平：

   ```
   (L + R) / 2：RMS -33.8 dB
   (L - R) / 2：RMS -37.9 dB
   ```

   相减之后只小了 4 dB，大部分声音还在。这段音频没有人声，是 5.1 声道混成的立体声，背景音乐和环境声本来就是左右不同的，所以「去人声」的效果很弱。换一首人声在正中间的流行歌曲试试，效果会明显得多。

5. 把 `alias.c` 中的 15000 换成其他频率，丢采样后的频率：

   | 原始频率 | 降到 16 kHz 后 |
   |---|---|
   | 9000 Hz | 7000 Hz |
   | 12000 Hz | 4000 Hz |
   | 15000 Hz | 1000 Hz |
   | 17000 Hz | 1000 Hz |

   规律：采样率 fs = 16 kHz 时，能表示的频率是 0～8 kHz。超过 8 kHz 的频率 f 会被「折叠」回来，变成 f 与最近的 fs 整数倍之差的绝对值：9 kHz → |9 − 16| = 7 kHz，12 kHz → 4 kHz，17 kHz → |17 − 16| = 1 kHz。以 fs/2 = 8 kHz 为镜子，频谱像纸一样被来回对折，所以 fs/2 也叫**折叠频率**。15 kHz 和 17 kHz 混叠成了同一个 1 kHz，这正说明混叠之后无法分辨原来的频率。

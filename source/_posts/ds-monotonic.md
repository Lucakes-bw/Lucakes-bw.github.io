> **本文目标**：理解单调栈和单调队列的思想；会用单调栈求下一个更大（更小）的元素；会用双端队列实现单调队列，求滑动窗口的最大值；会用均摊分析说明它们为什么是 O(n)。
>
> **前置知识**：《栈》、《队列》（双端队列）、《复杂度分析》（均摊分析）。

## 1. 问题：下一个更大的元素

给出每天的气温，对每一天，求**之后第一个更高的气温出现在哪一天**。比如：

```
下标:  0   1   2   3   4   5   6   7
气温: 73  74  75  71  69  72  76  73
答案:  1   2   6   5   5   6  -1  -1
```

第 2 天是 75 度，之后第一个更高的是第 6 天的 76 度；第 6 天之后没有更高的了，答案是 -1。

最直接的方法是对每一天向右逐个查找：

```c
void nextGreaterBrute(const int* a, int n, int* ans)
{
    for (int i = 0; i < n; ++i) {
        ans[i] = -1;
        for (int j = i + 1; j < n; ++j) {
            if (a[j] > a[i]) { ans[i] = j; break; }
        }
    }
}
```

最坏情况（气温一直下降，每一天都要找到末尾）是 O(n²)。

## 2. 单调栈

换个角度：**从左往右扫描时，把「还没有找到答案」的天放在一个栈中**。来了新的一天 `a[i]`，栈中所有比它低的天，答案都是 `i`，可以弹出了；然后把 `i` 入栈，等待它自己的答案。

```c
void nextGreater(const int* a, int n, int* ans)
{
    int* stack = malloc(n * sizeof(int));       // 存放下标，对应的值从栈底到栈顶递减
    int top = 0;
    for (int i = 0; i < n; ++i) {
        while (top > 0 && a[stack[top - 1]] < a[i]) {
            ans[stack[--top]] = i;              // a[i] 就是栈顶元素等待的「下一个更大」
        }
        stack[top++] = i;
    }
    while (top > 0) ans[stack[--top]] = -1;     // 剩下的右边没有更大的
    free(stack);
}
```

为什么只需要比较栈顶？因为栈中的值**从栈底到栈顶是递减的**：每次入栈之前，比新元素小的都已经被弹出了，所以栈中留下的都比新元素大。这种栈叫**单调栈**。新元素来了，只要栈顶不比它小，下面的就更不会比它小，可以停止比较。

### 2.1 为什么是 O(n)

`for` 循环中有一个 `while` 循环，看起来像 O(n²)。但是从整体看，**每个下标只入栈一次、最多出栈一次**，所以整个过程中 `while` 循环体一共最多执行 n 次。总的时间复杂度是 O(n)。这就是《复杂度分析》中的**均摊分析**：不看单次循环的最坏情况，而是看所有操作的总代价。

实测，用一直递减的数组（暴力解法的最坏情况），`-O2` 编译，并检查两种方法的结果完全一致：

```
下一个更大 n = 10000   暴力     26.1 ms，单调栈 0.027 ms，结果一致
下一个更大 n = 100000  暴力   1080.8 ms，单调栈 0.096 ms，结果一致
```

10 万个数据时，单调栈快了 1 万倍以上。

### 2.2 变形

把比较的方向和扫描的方向换一换，单调栈可以解决一组相似的问题：

| 问题 | 扫描方向 | 栈中保持 | 弹出条件 |
|---|---|---|---|
| 右边第一个更大的 | 从左往右 | 递减 | 栈顶 < 当前 |
| 右边第一个更小的 | 从左往右 | 递增 | 栈顶 > 当前 |
| 左边第一个更小的 | 从左往右 | 递增 | 栈顶 >= 当前，弹完后的栈顶就是答案 |

识别它的信号是：**对每个元素，找它左边或右边第一个比它大（小）的元素**。

## 3. 问题：滑动窗口最大值

一个长度为 k 的窗口从数组的左边滑到右边，每次移动一格，求每个窗口中的最大值。比如数组 `1 3 -1 -3 5 3 6 7`，k = 3：

```
窗口 [1 3 -1]       最大值 3
窗口 [3 -1 -3]      最大值 3
窗口 [-1 -3 5]      最大值 5
窗口 [-3 5 3]       最大值 5
窗口 [5 3 6]        最大值 6
窗口 [3 6 7]        最大值 7
```

对每个窗口都扫描一遍是 O(nk)。

## 4. 单调队列

关键的观察是：如果窗口中有两个元素 `a[j]` 和 `a[i]`，`j < i` 而且 `a[j] <= a[i]`，那么 **`a[j]` 永远不可能再成为最大值了**：只要 `a[j]` 还在窗口中，`a[i]` 也一定在（它更晚离开），而且不比 `a[j]` 小。

所以，用一个**双端队列**保存「将来还有可能成为最大值」的下标，它们对应的值从队头到队尾**递减**：

- 新元素从**队尾**加入之前，先从队尾删除所有不比它大的元素；
- 如果**队头**已经滑出窗口，从队头删除；
- 队头就是当前窗口的最大值。

```c
void windowMax(const int* a, int n, int k, int* out)
{
    int* dq = malloc(n * sizeof(int));          // 双端队列，存放下标，对应的值从队头到队尾递减
    int head = 0, tail = 0;                     // [head, tail) 是队列中的元素
    for (int i = 0; i < n; ++i) {
        while (tail > head && a[dq[tail - 1]] <= a[i]) {
            --tail;                             // 比 a[i] 小的，永远不可能再成为最大值
        }
        dq[tail++] = i;
        if (dq[head] <= i - k) {
            ++head;                             // 队头已经滑出窗口
        }
        if (i >= k - 1) {
            out[i - k + 1] = a[dq[head]];       // 队头就是窗口的最大值
        }
    }
    free(dq);
}
```

这里每个下标最多入队一次，所以直接用一个长度为 n 的数组和 `head`、`tail` 两个下标实现双端队列，不需要循环。

队列中存放的是**下标**而不是值，因为要靠下标判断元素是否已经滑出了窗口。

### 4.1 复杂度和实测

和单调栈一样，每个下标最多入队一次、出队一次，总的时间复杂度是 O(n)，**与窗口大小 k 无关**。实测（随机数据，`-O2`）：

```
窗口最大值 n = 100000  k = 1000：暴力      2.2 ms，单调队列 0.475 ms，结果一致
窗口最大值 n = 100000  k = 10000：暴力     23.1 ms，单调队列 0.476 ms，结果一致
窗口最大值 n = 1000000 k = 10000：暴力    254.9 ms，单调队列 4.844 ms，结果一致
```

暴力解法的耗时随 k 线性增长，单调队列的耗时只和 n 有关。另外可以注意到，暴力解法在 k = 1000 时只慢了 4 倍多，远没有 O(nk) 和 O(n) 的理论差距那么大：它的内层循环只是在连续的内存中求最大值，编译器用 SIMD 指令把它优化得非常快。这也提醒我们，**复杂度描述的是增长趋势，实际的常数因子同样重要**。

## 5. 常见错误

1. **栈或队列中存放值而不是下标**：无法写入答案的位置，也无法判断元素是否滑出窗口。
2. **弹出条件的 `<` 和 `<=` 搞混**：在有重复元素时结果可能不对，要根据题目「严格大于」还是「大于等于」仔细确定。
3. **看到 `for` 里面套 `while` 就认为是 O(n²)**：要用均摊分析，看每个元素一共被处理几次。
4. **滑动窗口中忘记删除过期的队头**：最大值可能来自已经离开窗口的元素。
5. **从队尾删除时用错了比较方向**：队列不再单调，队头不一定是最大值。

## 6. 小结

- 单调栈：栈中的元素保持单调，新元素入栈前弹出破坏单调性的元素，弹出时就找到了它们的答案；用于求每个元素左边或右边第一个更大（更小）的元素
- 单调队列：用双端队列保存可能成为最值的下标，队尾删除不可能的候选，队头删除过期的元素；用于滑动窗口的最值
- 每个元素只进出一次，均摊 O(n)；实测比暴力解法快了 1 万倍（下一个更大）和约 50 倍（窗口最大值，k = 10000）

## 7. 练习

1. 对数组中的每个元素，求它**左边**第一个比它**小**的元素的下标，没有则为 -1。用 `3 7 8 4 5 2` 测试。
2. 在 `windowMax` 中，如果把从队尾删除的条件 `a[dq[tail - 1]] <= a[i]` 改成 `<`，结果还正确吗？
3. （挑战）柱状图中有 n 根宽度为 1 的柱子，高度分别是 `h[0..n-1]`，求能画出的最大矩形的面积。比如 `2 1 5 6 2 3` 的答案是 10（高度 5 和 6 的两根柱子，以 5 为高，宽度为 2）。提示：以每根柱子的高度作为矩形的高，矩形能向左右延伸到第一根比它矮的柱子为止。

1. 从左往右扫描，栈中保持递增。对每个新元素，先弹出所有不比它小的元素（它们对后面的元素也没有用了，因为新元素更小而且更靠右），弹完之后的栈顶就是答案：

   ```c
   void prevSmaller(const int* a, int n, int* ans)    // 左边第一个比 a[i] 小的元素的下标
   {
       int* stack = malloc(n * sizeof(int));
       int top = 0;
       for (int i = 0; i < n; ++i) {
           while (top > 0 && a[stack[top - 1]] >= a[i]) {
               --top;
           }
           ans[i] = top > 0 ? stack[top - 1] : -1;
           stack[top++] = i;
       }
       free(stack);
   }
   ```

   对 `3 7 8 4 5 2`，结果是 `-1 0 1 0 3 -1`。

2. 仍然正确。改成 `<` 之后，相等的元素会同时留在队列中，队列从队头到队尾是「非严格递减」的，队头仍然是最大值，只是队列中可能多一些元素。用 `<=` 可以让队列更短。

3. 用单调栈同时找到每根柱子左边和右边第一根比它矮的柱子。栈中保持递增；当一根更矮的柱子到来时，栈顶的柱子不能再向右延伸了，以它为高的矩形就确定了，它左边的边界就是弹出后的栈顶：

   ```c
   long long largestRect(const int* h, int n)        // 柱状图中最大的矩形面积
   {
       int* stack = malloc((n + 1) * sizeof(int));
       int top = 0;
       long long best = 0;
       for (int i = 0; i <= n; ++i) {
           int cur = (i == n) ? 0 : h[i];                // 最后放一个高度为 0 的柱子，清空栈
           while (top > 0 && h[stack[top - 1]] > cur) {
               int height = h[stack[--top]];
               int left = top > 0 ? stack[top - 1] : -1;  // 左边第一个更矮的
               long long area = (long long)height * (i - left - 1);
               if (area > best) best = area;
           }
           stack[top++] = i;
       }
       free(stack);
       return best;
   }
   ```

   `2 1 5 6 2 3` 的结果是 10，`2 4` 的结果是 4。在末尾加一根高度为 0 的柱子，是为了让栈中剩下的柱子在最后都被处理到。时间复杂度 O(n)。

给定一个**严格升序**的整数数组 `nums`，把它转换成一棵**高度平衡**的二叉搜索树（每个节点左右两棵子树的高度差不超过 1）。

满足条件的树往往不止一棵。为了让答案唯一，本题规定：**每次取当前区间正中间的元素做根；区间长度为偶数时，取中间偏左的那个**（下标 `(l + r) / 2` 向下取整）。

**约束**

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 严格递增

**提示**：中间元素做根，左半部分递归建左子树，右半部分递归建右子树。

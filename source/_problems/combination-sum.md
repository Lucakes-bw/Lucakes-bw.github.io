给定一个**元素互不相同**的正整数数组 `candidates` 和目标值 `target`，找出所有和为 `target` 的组合。

`candidates` 中的同一个数可以**无限次**重复选用。两个组合只要所选数字的个数不完全相同，就算不同的组合。组合之间、组合内部的顺序都不限。

题目保证组合的总数少于 150 个。

**约束**

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`（附加用例里也有 `1`）
- `candidates` 中的元素互不相同
- `1 <= target <= 40`

**提示**：回溯时规定只能从当前位置及以后的数里选，这样同一个组合不会以不同顺序重复出现。先排序，遇到比剩余目标还大的数就可以提前结束。

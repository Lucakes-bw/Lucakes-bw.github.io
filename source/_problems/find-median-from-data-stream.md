**中位数**是有序整数列表中间的那个数；如果列表长度为偶数，中位数是中间两个数的平均值。比如 `[2, 3, 4]` 的中位数是 `3`，`[2, 3]` 的中位数是 `(2 + 3) / 2 = 2.5`。

实现 `MedianFinder` 类：

- `MedianFinder()`：初始化对象
- `addNum(num)`：把数据流中的整数 `num` 加入数据结构
- `findMedian()`：返回到目前为止所有元素的中位数。判题时允许 `10^-5` 的误差

**用例的格式**：第一项是依次调用的操作名，第二项是每次调用的参数；输出是每次调用的返回值，构造函数和 `addNum` 的位置是 `null`。

**约束**

- `-10^5 <= num <= 10^5`
- 调用 `findMedian` 之前，数据结构中至少有一个元素
- 最多调用 `5 * 10^4` 次 `addNum` 和 `findMedian`

**进阶**：如果所有数都在 `[0, 100]` 范围内，怎样优化？如果 99% 的数都在这个范围内呢？

**提示**：用两个堆把数据分成较小的一半和较大的一半：大根堆存较小的一半，小根堆存较大的一半，并保持大根堆最多比小根堆多一个元素。中位数就由两个堆顶决定。

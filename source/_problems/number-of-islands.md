给定一个由 `'1'`（陆地）和 `'0'`（水）组成的二维网格 `grid`，计算网格中**岛屿的数量**。

岛屿由**水平或竖直**方向上相邻的陆地连成，斜着相邻不算连通。可以认为网格的四周都是水。

**约束**

- `1 <= grid.length, grid[i].length <= 300`
- `grid[i][j]` 是 `'0'` 或 `'1'`

**提示**：把网格看成一张图，每块陆地是一个顶点。从每块还没访问过的陆地出发做一次 DFS / BFS，把整座岛标记掉，出发了几次就有几座岛。也可以用并查集。

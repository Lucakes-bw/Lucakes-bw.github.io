给定一个包含红色、白色和蓝色共 `n` 个元素的数组 `nums`，用整数 `0`、`1`、`2` 分别表示红、白、蓝。**原地**对它排序，使相同颜色的元素相邻，并按红、白、蓝的顺序排列。

不能使用库里的排序函数。函数不需要返回值，判题时检查调用之后的 `nums`。

**约束**

- `1 <= n <= 300`
- `nums[i]` 是 `0`、`1` 或 `2`

**进阶**：计数排序要扫两遍，你能只扫一遍、只用常数空间吗？

**提示**：荷兰国旗问题：用三个指针，`p0` 左边全是 0，`p2` 右边全是 2，`i` 从左往右扫：遇到 0 和 `p0` 交换，遇到 2 和 `p2` 交换（交换过来的数还没看过，`i` 先不动）。

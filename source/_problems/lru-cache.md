设计一个满足 **LRU（最近最少使用）** 淘汰策略的缓存，实现 `LRUCache` 类：

- `LRUCache(capacity)`：以正整数 `capacity` 作为容量初始化缓存
- `get(key)`：如果 `key` 在缓存中，返回对应的值，否则返回 `-1`
- `put(key, value)`：如果 `key` 已经存在，更新它的值；否则插入这组 `key-value`。插入之后如果数量超过容量，就淘汰**最久未使用**的那个

`get` 和 `put` 都算「使用」了这个 key。两个操作都必须是 **O(1)** 的平均时间复杂度。

**用例的格式**：和 LeetCode 一样，第一项是依次调用的操作名，第二项是每次调用的参数；输出是每次调用的返回值，构造函数和 `put` 的位置是 `null`。

**约束**

- `1 <= capacity <= 3000`
- `0 <= key <= 10^4`，`0 <= value <= 10^5`
- `get` 和 `put` 最多调用 `2 * 10^5` 次

**提示**：哈希表负责 O(1) 找到节点，双向链表负责维护使用顺序：每次使用就把节点移到链表头，淘汰时删掉链表尾。用头尾两个哨兵节点可以省掉很多边界判断。

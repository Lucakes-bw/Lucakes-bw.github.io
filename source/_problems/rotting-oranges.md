在一个 `m x n` 的网格中，每个格子可能是：

- `0`：空格
- `1`：新鲜橘子
- `2`：腐烂的橘子

每过一分钟，腐烂橘子**上下左右**相邻的新鲜橘子都会腐烂。返回直到没有新鲜橘子为止所需的**最少分钟数**；如果有橘子永远不会腐烂，返回 `-1`。

**约束**

- `1 <= m, n <= 10`
- `grid[i][j]` 只会是 `0`、`1` 或 `2`

**提示**：多源 BFS：一开始把所有腐烂的橘子同时放进队列，一层一层向外扩散，层数就是分钟数。最后检查是否还剩新鲜橘子。

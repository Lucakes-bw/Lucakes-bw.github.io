二叉树中的一条**路径**是指一串节点，序列中每对相邻节点之间都有一条边相连，并且同一个节点最多出现一次。路径至少包含一个节点，不一定经过根节点。

路径和是路径上所有节点值的总和。给定二叉树的根节点 `root`，返回最大的路径和。

**约束**

- 节点数在 `[1, 3 * 10^4]` 范围内
- `-1000 <= Node.val <= 1000`

**提示**：定义 `gain(node)` 为从 `node` 出发、一直向下走能得到的最大和（负数的分支不如不要，按 0 算）。经过 `node` 拐弯的最大路径 = `node.val + gain(left) + gain(right)`，用它更新全局答案；返回给父节点的只能选一边：`node.val + max(gain(left), gain(right))`。

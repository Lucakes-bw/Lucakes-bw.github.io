给定二叉树的根节点 `root` 和整数 `targetSum`，统计有多少条路径上的节点值之和等于 `targetSum`。

路径不需要从根节点开始，也不需要在叶子节点结束，但方向必须是**向下**的（只能从父节点走到子节点）。

**约束**

- 节点数在 `[0, 1000]` 范围内
- `-10^9 <= Node.val <= 10^9`
- `-1000 <= targetSum <= 10^9`

注意：路径和可能超出 32 位整数的范围。

**提示**：和「和为 K 的子数组」一样用前缀和：DFS 时维护从根到当前节点的前缀和，并用哈希表记录这条路径上每个前缀和出现的次数；回溯离开节点时要把它的前缀和计数减掉。

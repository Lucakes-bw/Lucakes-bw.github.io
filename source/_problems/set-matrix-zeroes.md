给定一个 `m x n` 的矩阵，如果某个元素是 `0`，就把它所在的**整行和整列**的元素都设为 `0`。

要求**原地**修改，函数不需要返回值，判题时检查调用之后的 `matrix`。注意：只有原本就是 `0` 的元素才会引起置零，被置零的元素不会继续扩散。

**约束**

- `1 <= m, n <= 200`
- `-2^31 <= matrix[i][j] <= 2^31 - 1`

**进阶**：用 O(m + n) 的额外空间很直接，你能只用常数空间吗？

**提示**：可以把第一行和第一列当作标记数组，只是要先单独记下它们自己原本有没有 0。

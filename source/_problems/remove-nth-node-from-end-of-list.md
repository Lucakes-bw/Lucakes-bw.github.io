给定一个链表，删除链表的**倒数第 `n` 个**节点，返回删除之后链表的头节点。

**约束**

- 链表的节点数为 `sz`，`1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**进阶**：你能只遍历一趟吗？

**提示**：让快指针先走 `n` 步，然后快慢指针一起走，快指针到末尾时，慢指针正好停在要删除节点的前一个。用哑节点可以统一处理删除头节点的情况。

给定一个长度为 `n` 的链表，每个节点除了 `next` 指针之外，还有一个 `random` 指针，它可以指向链表中的任何节点，也可以为 `null`。

构造这个链表的**深拷贝**：新链表由 `n` 个**全新**的节点组成，每个新节点的值和对应原节点相同，新节点的 `next` 和 `random` 也都指向新链表中对应的节点，使新链表和原链表表示相同的结构。新链表中的指针**不能指向原链表的节点**，返回新链表的头节点。

**用例的格式**：每个节点写成 `[val, random_index]`，`random_index` 是 `random` 指向的节点下标，不指向任何节点时为 `null`。判题时也把你返回的链表按这个格式输出，并检查它没有用到原链表的节点。

**约束**

- `0 <= n <= 1000`
- `-10^4 <= Node.val <= 10^4`
- `Node.random` 为 `null` 或指向链表中的节点

**提示**：用哈希表记录「原节点 → 新节点」，先建出所有新节点，再第二遍连接 `next` 和 `random`。O(1) 额外空间的做法：把每个新节点插在对应原节点后面（A → A' → B → B'），这样 `A'.random = A.random.next`，最后再把两条链表拆开。
